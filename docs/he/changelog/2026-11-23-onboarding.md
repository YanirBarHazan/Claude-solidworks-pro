# מה חדש (23/11/2026, גרסה 2.3): התקנה בשורה אחת, הלשונית נפתחת לבד, ושאלות פתיחה בכל פעם

## הבעיה
- כמה משתמשים התקינו את המיומנות ולא ראו את לשונית Claude בסולידוורקס. העתקת המיומנות, או העלאה שלה באפליקציית Claude, רק שמה קבצים על הדיסק. הלשונית צריכה תהליך רקע קטן, ואף אחד לא הפעיל אותו.
- אחרי עדכון הלשונית נשארה ישנה, כי התהליך שרץ מחזיק את הקוד הישן בזיכרון.
- קלוד דילג הרבה פעמים על שאלות הפתיחה: רמת אימות, דוח סקירה, ומה הוא הבין מהתכנון. הן היו שלב 2 בתהליך, וההנחיות של הלשונית בכלל לא הזכירו אותן.

## מה השתנה
- **התקנה בשורה אחת, גם למי שלא מכיר קוד:** מקש Windows + R, מדביקים שורה אחת, או לחיצה כפולה על `install.cmd` מקובץ ה-ZIP. ההתקנה מתקינה פייתון ו-Claude Code אם חסרים, את המיומנות ואת לשונית Claude, ומדפיסה שורה לכל שלב.
- **`scripts/install_panel.py`:** מתקין, מעדכן ובודק את הלשונית. הוא שומר עותק קבוע ב-`~/.solidworks-api/app`, עוצר לשונית ישנה שעדיין רצה, מפעיל את החדשה, ומוסיף קיצור דרך שמפעיל אותה בכל כניסה ל-Windows. `--check` מדווח, `--remove` מבטל.
- **שלב 0 ב-SKILL.md, בכל סשן:** קלוד בודק את הלשונית ומתקן אם צריך. כך כל דרך התקנה (העתקה, העלאה באפליקציה) נגמרת בלשונית שעובדת.
- **שאלות הפתיחה הן עכשיו התשובה הראשונה**, גם ב-Claude Code וגם בלשונית: רמת אימות, דוח סקירה, ומה קלוד הבין עם הערכים שהוא מניח. לכל שאלה יש ברירת מחדל מומלצת. התשובות נשמרות ב-`project.json` ולא נשאלות שוב באותו פרויקט.
- הלשונית מוצאת גם Claude Code שהותקן במתקין הרשמי (`~/.local/bin`).
- קובץ `VERSION` במיומנות (2.3.0).
