# מה חדש (19/11/2026): יומן יומי - לראות מה Claude עשה היום ב-SolidWorks

- **נרשם לבד**: כל סקריפט שמתחבר ל-SolidWorks, וכל פקודת `swx` שמשנה משהו, כותבים שורה ל-
  `~/.solidworks-api/daylog/<date>.jsonl` - שעה, הצליח / שגיאה, אילו קבצים נפתחו, ולכל הרכבה פתוחה כמה רכיבים
  ב-Fix / צפים / במייטים וכמה מייטים יש בה.
- **דף אחד ליום**: `python scripts/daylog.py [date]` מחבר את ההרצות, שיחות Claude Code של היום (בקשות, כלים,
  סקריפטים, טוקנים) והטאב בתוך SolidWorks לציר זמן אחד, ומסמן אזהרות איפה נשבר כלל: הרכבה ב-Fix במקום מייטים,
  רכיבים צפים, הרצה שפתחה הרבה קבצים, הרצות שנכשלו.
- **כלל חדש**: פותחים רק את המסמכים שהמשימה משנה; קוראים הרכבה מתוך ההרכבה, לא פותחים כל קובץ רכיב.
- **בדיקת "מוחזק במייטים"**: `asmtools.check_held(asm)` מכשילה הרכבה (וכל קובץ תת־הרכבה) עם יותר מרכיב
  אחד ב-Fix או רכיב צף, ורושמת את זה ביומן הבדיקות; `audit.py` יוצא עם קוד 1 באותו מצב. מיקום ב-Fix עובר רק
  עם `fixed_ok="<סיבה>"` כשאישרת אותו (מאות רכיבים חוזרים על 2019).
