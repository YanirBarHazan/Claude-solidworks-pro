# What's new (2026-11-23, v2.4): English tab, clear permissions, pinned install, lighter start

- **The Claude tab speaks English too.** A small flag at the top of the tab switches Hebrew / English: labels,
  quick prompts, the tab's own messages, the left-to-right layout, and Claude's replies (every message carries
  `ui_language`). The choice is saved; the first run follows the Windows display language.
- **Permissions in plain words.** The README now says exactly what Claude may do in the tab without asking
  (including running Python, which means any code), and lists everything the installer changes on the PC and how
  to remove it. [README: Permissions and what it changes on your PC](../../README.md#permissions-and-what-it-changes-on-your-pc)
- **Install a fixed version.** `install.ps1 -Ref v2.4.0` (or `$env:SW_INSTALL_REF`) installs a release tag, a
  branch or a commit instead of the latest `main` - for teams that review the code before installing.
- **Small changes skip the start questions.** A value, a fillet, a rename or an export on an existing model is
  done straight away at the project's verification level (default standard), with one closing line naming the
  level. New designs, structure changes and rebuilds still start with the questions.
- **Tests that run without SolidWorks.** `tests/` covers the parameter file, hand-edit detection, pattern
  planning, the review log and the tab's text in both languages; GitHub Actions runs them on Windows and Linux.
- **One number for the big assembly.** The README states the field-tested size the skill documents (770
  components) and the measured per-call speed-up (0.15 ms instead of ~15 ms).
