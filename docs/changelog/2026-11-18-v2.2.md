# What's new (2026-11-18, v2.2): Claude inside SolidWorks, 5-100x faster API calls, design for change

- **A Claude chat tab in the SolidWorks Task Pane** - select a face, hole or component, type what you want (Hebrew
  or English), Claude Code works in the background and answers in the tab: live steps, Stop, approve / reject
  cards, save folder, file attachments. No add-in, no C#, no admin rights. [Panel](../../skill/solidworks-api/references/panel.md)
- **Fast mode** in `connect()` (`CommandInProgress`): a COM call costs 0.15 ms instead of ~15 ms. Capability suite
  397 s -> 117 s; on a 739-component skeleton assembly, checking every position 62.6 s -> 6.8 s; a real
  design change on a 2,000+ component assembly 1,181 s -> 619 s.
- **Fast commands** (`swx.py info / set / fillet / save / run`): a warm worker answers in ~0.2 s, selection
  geometry in part AND assembly coordinates, in-place value changes also inside nested sub-assemblies.
  Token benchmark of 5 fixed requests: -86% input tokens, every result checked by measurement.
- **Design for change** ([assemblies 14](../../skill/solidworks-api/references/assemblies.md)): every value a client may
  change is one global SolidWorks propagates - span edit + full re-check in 5 s instead of regenerating files.
- Version notes 36-49 and new 2019 pitfalls (fast mode survives a killed client, first component comes in fixed,
  component equations need the part active, Measure arc centre).
