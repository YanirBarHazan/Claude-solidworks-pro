# What's new (2026-11-18): drawings, a light start check, and a review report

- **Drawings in one call** (`drawings.py`): views at a standard scale, the model's own dimensions, section A-A,
  tolerances, BOM + balloons for assemblies, PDF / DXF, ISO or company title block - each checked with numbers
  (no dangling dimension, expected values present, BOM = assembly counts). [Drawings](../../skill/solidworks-api/references/drawings.md)
- **Light start**: `preflight.py` takes seconds on a known SolidWorks version and runs the full 13-capability suite
  only on a version never tested, writing a local report. [Setup](../../skill/solidworks-api/references/setup.md)
- **Start questions in every project** (verification level quick / standard / strict, start check, review report,
  an understanding check) and a **one-page review PDF**: what was built, proven, skipped, assumed.
  [Dialogue](../../skill/solidworks-api/references/dialogue.md)
- Tested live on SolidWorks 2019 (suite 13 / 13). Version notes 32-35 added.
