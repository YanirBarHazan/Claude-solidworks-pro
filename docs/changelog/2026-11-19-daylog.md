# What's new (2026-11-19): a day log - see what Claude did in SolidWorks today

- **Recorded automatically**: every script that connects to SolidWorks, and every `swx` command that changes
  something, writes one line to `~/.solidworks-api/daylog/<date>.jsonl` - time, ok / error, the files it opened,
  and for each open assembly how many components are Fixed / floating / mated and how many mates it has.
- **One page per day**: `python scripts/daylog.py [date]` merges the SolidWorks runs, the Claude Code
  conversations of the day (requests, tools, scripts, tokens) and the Claude tab in SolidWorks into one timeline,
  and lists warnings where a rule was broken: an assembly held by Fix instead of mates, floating components, a run
  that opened many files, failed runs.
- **New rule**: open only the documents the task changes; read an assembly from the assembly, not by opening every
  component file.
- **Held-by-mates gate**: `asmtools.check_held(asm)` fails an assembly (and every sub-assembly file) with more
  than one Fixed component or any floating one, and logs it in the review log; `audit.py` exits 1 on the same.
  Fixed placement passes only with `fixed_ok="<reason>"` when the user approved it (700+ repeats on 2019).
