# What's new (v2.5): parallel agents, update notice, any AI client, one contract, a clearer tab

- **Parallel agents.** A bigger job is split into independent parts that background agents build at the same
  time - 3 by default, 2-8 in the tab's menu; the rest wait in a queue. They work on hidden documents
  (`run --background`, `--doc PATH`), so the document you look at never changes, and reach SolidWorks through one
  worker that runs one command at a time. The tab shows a flow chart (main -> agents -> merge), a card per agent
  with its current step and a picture of its result (`snapshot`); when all have finished the main Claude checks
  each result and brings them together.
- **Update notice.** At start and once a day the tab asks GitHub whether a newer version is out: Update now /
  Not now / What's new. One click runs the installer for that release; the tab closes and comes back by itself.
- **The tab comes back reliably.** An error can no longer end the watcher that adds the tab when SolidWorks
  opens, and a slow SolidWorks start is retried.
- **Any AI client (MCP).** `mcp/server.py` serves the same commands to Claude Desktop, Cursor and other MCP
  clients, plus `engineering_guide` - the method for a model that never saw the skill.
- **One contract.** `contracts/worker_commands.json` defines every worker command and argument; the worker
  refuses anything else, and a test fails when the worker, `swx.py`, the MCP server or the tab's prompt drifts.
- **A clearer tab.** The open document and the selection in words under the title; folder, attach, new chat and
  agents at a time in a small menu; while Claude works a short list of steps in plain words; under each reply
  steps · seconds · tokens. Routine checks are not reported when they pass.
- **Plan first, fewer wasted tokens.** Bigger work starts with a plan card - Do it all / One step, then stop /
  Change; in step mode Claude stops after each step: Continue / Stop here.
- **Tests:** 61 without SolidWorks (incl. a real MCP round-trip and the agent queue); `live_check.py` covers what
  needs SolidWorks.
