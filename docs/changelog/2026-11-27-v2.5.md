# What's new (v2.5, in testing): drawing to part, any AI client, one contract, a clearer tab

- **From a 2D drawing.** `drawing_read.py` reads a DXF (or DWG with the ODA converter): views, closed outlines
  (strict chaining - a junction stops the chain and is reported), dimensions as printed, the drawing scale from
  printed vs. drawn sizes, title block fields, bend notes paired to bend lines. It says DIRECT (the drawing alone
  fixes the part) or NOT_DIRECT with the reasons. `drawing_build.py` builds flat parts and proves bounding box and
  volume against the drawing's own numbers (exact area with arcs). Bent sheet metal is next, after the API check
  on a live SolidWorks (`probe_api.py`).
- **Any AI client (MCP).** `mcp/server.py` serves the same commands to Claude Desktop, Cursor and other MCP
  clients, plus `read_drawing` and `engineering_guide` - the method for a model that never saw the skill.
- **One contract.** `contracts/worker_commands.json` defines every worker command and argument; the worker
  refuses anything else, and a test fails when the worker, `swx.py`, the MCP server or the tab's prompt drifts.
- **A clearer tab.** No SEL / DIR strip: the open document and the selection in words under the title; the save
  folder, attach and new chat in a small menu. While Claude works: a short list of steps in plain words. Under
  each reply: steps · seconds · tokens, a click opens the steps.
- **Plan first, fewer wasted tokens.** Bigger work starts with a plan card - Do it all / One step, then stop /
  Change. In step mode Claude stops after each step with its measured result: Continue / Stop here.
- **Tests:** 65, all without SolidWorks, including a real MCP round-trip over stdio. `live_check.py` covers what
  needs SolidWorks.
